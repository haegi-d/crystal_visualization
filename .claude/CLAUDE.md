# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
# Install (editable, with dev tools)
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

# Format + lint (run before every commit)
black . && ruff check .

# Tests
pytest                          # all tests
pytest tests/test_select.py     # single file
pytest -k "test_find_defect"    # single test

# CLI render
python scripts/render.py config/my_run.toml
```

`bpy` (Blender) is intentionally absent from `pyproject.toml`. To use the `blender` backend either run the script inside Blender (`blender --background --python script.py`) or `pip install bpy` manually.

## Architecture

The public API is a single stateful class, `CrystalRenderer` (`crystal_visualization/renderer.py`), with chainable methods. Each method stores its result internally and returns `self`. Calling `render()` triggers lazy cluster-building via `_build_cluster()`.

The class is a thin orchestrator: every pipeline stage is implemented as plain functions in its own module, called by the renderer.

**Pipeline flow:**

```
parse.load()          → ASE Atoms (full structure)
select.find_defect()  → atom index of the defect site
select.select_cluster() → Atoms subset within cutoff radius (PBC-aware via MIC)
select.get_bonds()    → list[(i, j)] using covalent-radius cutoffs
backends/<name>.render() → output file
```

**Backend selection** (`backend=` arg on `render()`):
- `matplotlib` — fast 2D orthographic draft; no Blender needed
- `plotly` — interactive 3D in Jupyter; hover shows species/index/distance
- `blender` — final publication render; requires `bpy`

All three backends receive the same arguments: `(cluster, center_index, camera, style, output, bonds)`.

**Style presets** live in `config/styles/<name>.toml`. Adding a new journal style is a file addition with no code changes. Keys: `[figure]`, `[atoms.colors]`, `[atoms.radii]`, `[bonds]`, `[annotations]`.

**Output strategy** (blender backend): atoms/bonds render to a transparent TIFF; cell edges, labels, and scale bar are a separate SVG layer generated by `annotate.py` using `svgwrite`. The two are composited by `export.py` via `cairosvg` + `Pillow`.

## Coding conventions (from STYLE.md)

- Type hints required on all public function signatures; use `from __future__ import annotations` at the top of every file.
- Docstrings: one line max, describes return value or non-obvious side effect. No parameter lists.
- `logging.getLogger(__name__)` in library code; `print()` only in scripts/notebooks.
- Chemical symbols keep their capitalization (`Er`, `Y`, `O`).
- Tests use real ASE output and real fixture files in `tests/fixtures/` — no mocking of ASE or the filesystem.
- `bpy` imports inside `backends/blender.py` must be guarded so the rest of the package imports without Blender installed.
- Git commits: imperative mood, present tense (`add neighbor selection`).
